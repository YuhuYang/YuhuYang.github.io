句法计量软件：quansyn

quansyn 是用于句法计量分析的系列项目，quansyn 家族包括 quansyn python package、quansyn mini app、quansyn studio app。

README

  • 安装方式：可通过 pip install quansyn 安装，并在 Python 环境中使用。
  • API 文档：主要 API 说明见项目 README。
  • quansyn mini：开发早期 UI，页面简洁，提供 quansyn 最基础功能。
  • quansyn studio：enhanced UI，除句法指标计算和语言网络边抽取外，还提供句法分析、句法树编辑与可视化、网络分析与可视化等进阶功能。
