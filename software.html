句法计量软件：QuanSyn

QuanSyn 是一个用于句法计量分析的 Python 工具包，包含 depval、lingnet、lawfitter 三个核心模块。

README

  • 安装方式：支持 pip 安装（pip install quansyn）与源码安装。
  • 模块说明：depval（依存指标），lingnet（语言网络），lawfitter（统计规律拟合）。
  • 项目许可：MIT License。
  • 维护信息：作者 Yang Mu；协作者 Haitao Liu；邮箱 yuhu@zju.edu.cn。
